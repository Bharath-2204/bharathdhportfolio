## Platform

web

## Users
Recruiters and technical hiring managers evaluating Bharath Dibbadahalli Hanumanthappa for Cyber Threat Intelligence (CTI) Analyst, SOC Analyst, Vulnerability Management Analyst, and Application Security Engineer roles. Recruiters skim: current role, résumé, strongest work. Hiring managers dig: project details, demos, source code, write-ups.

## Product Purpose
A single-page personal portfolio that gets the visitor to the résumé and the strongest projects within seconds, and lets a technical reader verify the work through demos, GitHub repos, and Medium write-ups.

## Positioning
Current Vulnerability Management Analyst at Resilience, Inc. who builds his own security tooling: an evidence-reviewed threat intelligence engine (Ugroza), an EASM dashboard, a pfSense/Suricata/Splunk SOC lab, and a physical attack surface mapper.

## Operating Context
Visitors arrive from a résumé link, LinkedIn, or a job application. Desktop during screening, phone when forwarded. Deployed to GitHub Pages under /bharathdhportfolio/ (Vite + React + Tailwind + shadcn/ui, built by a GitHub Actions workflow on push to main).

## Capabilities and Constraints

- Every other existing project appears once under "More projects"; the AWS hardening project must be easy to find for AppSec applications.
- Existing demo videos, GitHub links, Medium links, certificate link, and résumé PDF are the destinations to preserve.
- Claims and metrics come only from the existing portfolio, the résumé (public/Bharath_Updated_V2.pdf), and the project repos.
